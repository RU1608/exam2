# Sales Recruitment Project 🎯

Репозиторий содержит инструменты, методологию и аналитические материалы для оптимизации процесса рекрутинга в сфере продаж (Sales Hiring). Проект направлен на сокращение времени закрытия вакансий (Time-to-Hire) и повышение качества кандидатов (Quality of Hire).

---

## 📌 Основные модули проекта

*   **`scouting/`** — Скрипты для парсинга и автоматизации поиска кандидатов на профильных платформах (HeadHunter, LinkedIn, Habr Career).
*   **`assessment/`** — Оценочные листы (Scorecards), тестовые задания и кейсы для валидации навыков продаж.
*   **`analytics/`** — Дашборды и метрики воронки подбора (конверсии, стоимость привлечения, когортный анализ).
*   **`templates/`** — Шаблоны писем, скрипты "холодных" звонков и офферов для Sales-специалистов.

---

## 🚀 Воронка подбора (Sales Hiring Pipeline)

Проект автоматизирует и структурирует следующие этапы:

1. **Скрининг (Screening):** Первичный отбор по ключевым навыкам (B2B/B2C, средний чек, цикл сделки).
2. **Интервью по компетенциям (Competency Interview):** Оценка навыков ведения переговоров, работы с возражениями и ориентации на результат.
3. **Ролевая игра / Кейс (Roleplay):** Симуляция реального звонка или встречи с клиентом.
4. **Финальное собеседование (Final Match):** Знакомство с Head of Sales и проверка Alignment с культурой компании.

---

## 🛠️ Технологический стек / Инструменты

*   **Backend / Скрипты:** Python 3.10+ (BeautifulSoup, Requests)
*   **Интеграции:** ATS API (Huntflow / Potok / Recruitee)
*   **Аналитика:** Pandas, BI Tools (Tableau / PowerBI)
*   **Стили и документация:** Markdown, Notion-like структуры
